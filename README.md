# Uelsen Masters

Gameshow für 3–8 Spieler. Version 1.11 mit 19 Spielen, Show-Musik und Offline-Funktion.

Die App wird durch GitHub Actions aus den sechs Dateien `site.part-01` bis `site.part-06` veröffentlicht. Die sechs Dateien bilden gemeinsam ein ZIP-Archiv; die Aufteilung hält jede Datei unter 8 MB. Die Veröffentlichung entpackt ausschließlich den vorbereiteten App-Bestand.

Nach der Veröffentlichung die unter Settings → Pages angezeigte HTTPS-Adresse in Safari auf dem iPad öffnen. Offline bereit abwarten, dann Teilen → Zum Home-Bildschirm. Anschließend ohne WLAN testen.

Eigene Spielstände und ergänzte Medien bleiben lokal auf dem Gerät.
